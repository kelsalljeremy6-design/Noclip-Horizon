
# Noclip Horizon

A standalone Android companion project for the Noclip Horizon experience.

## Goals
- Build a clean Android companion dashboard.
- Keep the existing NoclipVRLauncher project untouched.
- Prepare the project for future Meta Quest integration.
- Use GitHub Actions for automated Android builds.

## Development
The project will be built incrementally, with each milestone tested before adding more features.
